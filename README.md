# HVAC_skill

Скилл для Claude: проектирование систем отопления зданий по российским нормам
(СП 50 / 60 / 131 / 402) — от разбора архитектурного проекта до выпуска листов
марки ОВ на подложке АР.

**Версия:** 0.1.0-beta · **Лицензия:** MIT

Скилл собран из фактического рабочего цикла — проекта отопления спортзала
(г. Кинель, мкр. Лебедь, 112 м², ТП + догрев конвекторами, газовая котельная),
а не написан абстрактно. Методика, проверки и скрипты вытащены из того, что
реально делалось и перепроверялось.

## Что делает

| Этап | Содержание |
|---|---|
| Исходные данные | разбор PDF/DXF архитектурного проекта, таблица «данные → лист», список открытых вопросов |
| Теплотехника | R₀ по слоям, вентфасад, проверка по ГСОП, метод зон для грунта |
| Теплопотери | по помещениям, надбавки β и на врывание, вентиляция, блок самопроверки |
| Тёплый пол | теплосъём, предел температуры поверхности, раскладка улиткой, длины петель |
| Котельная | котёл, бойлер, расширительный бак, защита теплообменника, СП 402 |
| Записка | расчётно-пояснительная с разделом контроля расчёта |
| Чертежи | листы ОВ наложением на подложку АР, экспорт DXF |

Главный принцип: **каждое число в записке имеет адрес** — лист АР, пункт СП
или расчёт из числа, у которого адрес уже есть. Всё остальное объявляется
допущением и попадает в раздел открытых вопросов.

## Скрипты

Зависимости: Python 3.8+, для `sheet_pdf.py` — `reportlab` и `pypdf`.
`heatloss.py`, `spiral.py` и `dxf_export.py` работают на голом Python.

```bash
# теплопотери
python3 scripts/heatloss.py assets/project_template.json --md > teplopoteri.md

# раскладка петли улиткой
python3 scripts/spiral.py --w 3400 --h 2280 --step 150 --offset 150 \
        --name С1 --supply 6.3 --json loop_S1.json

# DXF
python3 scripts/dxf_export.py --loops loop_*.json --label-loops --out ОВ-05.dxf

# лист на подложке АР
python3 scripts/sheet_pdf.py --ar AR.pdf --page 5 --calib calib.json \
        --layer ov_cokol.json --loops loop_*.json --out ОВ-05.pdf
```

`sheet_pdf.py` **отказывается собирать лист**, если невязка калибровки по маркам
осей хуже 0,2 % — накладывать план на неравномерно отмасштабированную подложку
нельзя, а заметить это постфактум невозможно.

## Проверка

Расчётный блок сверен с ручным расчётом по проекту Кинель:

| Проверка | Результат |
|---|---|
| Rтр по СП 50, группа 2, ГСОП 4 449 | стены 2,535 / чердак 3,380 / окна 0,522 — совпало |
| Замыкание теплового баланса | 0 Вт расхождения |
| Сумма площадей зон грунта = площадь пола | 0,00 % |
| Контроль длины петли A/s | +4…5 % (перемычки улитки) |
| Отказ при невязке калибровки | срабатывает |

## Ограничения беты

- `spiral.py` работает с прямоугольными полями; сложная форма разбивается вручную.
- Гидравлический расчёт сети не реализован — только длины и расходы.
- Номенклатура сверена в июле 2026, требует проверки по каталогам перед выпуском
  спецификации.
- Разделы ВК и К — только принципиальные решения.
