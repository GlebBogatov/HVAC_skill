# Расчёт теплопотерь

## 1. Состав

Q = Qтрансм + Qвент + Qинфильтр − Qтеплопоступления

### Трансмиссионные

Qтрансм = Σ Aᵢ · Uᵢ · (tв − tн) · nᵢ · βᵢ

где β — надбавка на ориентацию, n — коэффициент смежного объёма.

### Надбавка β на ориентацию (СНиП 41-01, прил.)

| Ориентация | β |
|---|---|
| С, СВ, СЗ, В | 1,10 |
| ЮВ, З | 1,05 |
| Ю, ЮЗ | 1,00 |

Применяется **только к конструкциям, контактирующим с наружным воздухом**:
наружные стены, окна, двери, покрытия. К заглублённым частям, полам по грунту
и внутренним стенам — не применяется.

Если ориентация в АР не показана (нет указателя севера — типовая ситуация),
принять усреднённое β = 1,10 и вынести в открытые вопросы с оценкой влияния.

### Надбавка на врывание холодного воздуха через наружные двери

Дверь без тамбура, при высоте здания H в метрах:

| Тип входа | Надбавка к Qдвери |
|---|---|
| Одинарная дверь без тамбура | 0,22 · H |
| Двойная дверь с тамбуром | 0,27 · H |
| Двойная дверь без тамбура | 0,34 · H |
| Тройная дверь с двумя тамбурами | 0,20 · H |

При H = 7,9 м одинарная дверь без тамбура даёт множитель 1,74 — то есть
теплопотери двери увеличиваются почти втрое. Для маленькой кладовой это может
быть треть всей нагрузки. Про эту надбавку забывают чаще всего.

Не применяется к дверям, оборудованным воздушно-тепловой завесой.

### Вентиляционные

Qвент = 0,28 · L · ρ · (tв − tн)

где L — расход наружного воздуха, м³/ч; ρ = 353/(273 + tв), кг/м³;
0,28 = c/3,6 при c = 1,005 кДж/(кг·К).

Расход задаётся либо кратностью (L = n · V), либо нормируемым притоком.

| Помещение | Кратность / расход | Основание |
|---|---|---|
| Жилые комнаты | 1,0 ч⁻¹ или 3 м³/ч на м² | СП 60 |
| Спортивный зал, дежурный режим | 1,0 ч⁻¹ | инженерное решение |
| Спортивный зал при занятиях | 80 м³/ч на человека | СП 118 |
| Кухня с газовой плитой | 100 м³/ч | СП 60 |
| Санузел, ванная | 25 / 25 м³/ч | СП 60 |
| Кладовые, подсобные | 0,3…0,5 ч⁻¹ | инженерное решение |
| Котельная с газовым котлом | 3 ч⁻¹ + воздух на горение | СП 402 |

Для помещений с эпизодическим пребыванием обосновать дежурный режим:
кратковременный провал температуры при полном воздухообмене допускается, иначе
котёл подбирается втрое больше нужного.

**Воздух на горение** для котла с открытой камерой — примерно 12…15 м³ на 1 м³
газа, то есть около 1,6 м³/ч на 1 кВт мощности. Для котла с закрытой камерой
(коаксиальный дымоход) воздух берётся с улицы, на теплопотери котельной не влияет.

### Теплопоступления

Учитывать разумно и в минус:

| Источник | Ориентир |
|---|---|
| Газовый котёл 15…25 кВт в котельной | 250…400 Вт |
| Бойлер косвенного нагрева 160 л | 80…120 Вт |
| Неизолированные трубы в помещении | 30…60 Вт/м |
| Человек в покое / при нагрузке | 100 / 200…400 Вт |
| Освещение | по установленной мощности |

Бытовые теплопоступления и солнечную радиацию в расчёт **отопительной нагрузки
не включать** — нагрузка считается на условия, когда их нет.

## 2. Формат входного JSON для scripts/heatloss.py

```json
{
  "project": "Пример",
  "climate": {"t_out": -27.0, "t_ot": -4.7, "z_ot": 196},
  "building_group": 2,
  "constructions": {
    "НС-1": {"layers": [[0.19, 0.47], [0.10, 0.042]], "R_se": 0.115, "note": "вентфасад"},
    "ОК-В":  {"R": 0.70},
    "ЧП":    {"layers": [[0.02, 0.18], [0.25, 0.041], [0.02, 0.18]], "r": 0.88, "R_se": 0.115}
  },
  "rooms": [
    {
      "name": "Зал", "area": 58.23, "height": 3.07, "t_in": 18,
      "envelopes": [
        {"constr": "НС-1", "area": 30.5, "contact": "outdoor", "beta": 1.10},
        {"constr": "ОК-В", "area": 22.5, "contact": "outdoor", "beta": 1.10},
        {"constr": "ЧП",   "area": 58.23, "contact": "attic",  "n": 0.9}
      ],
      "vent": {"mode": "ach", "value": 1.0},
      "gains": 0
    },
    {
      "name": "Кладовая", "area": 18.37, "height": 2.27, "t_in": 16,
      "envelopes": [
        {"constr": "НС-2", "area": 8.2, "contact": "outdoor", "beta": 1.10},
        {"constr": "ДН",   "area": 1.85, "contact": "outdoor", "beta": 1.10,
         "door_infiltration": {"H": 7.9}}
      ],
      "ground": {"perimeter": 12.4, "wall_depth": 1.27, "floor_area": 18.37,
                 "R_add_wall": 2.5, "R_add_floor": 1.727},
      "vent": {"mode": "ach", "value": 0.5}
    }
  ]
}
```

Поля:

- `contact`: `outdoor` | `attic` | `unheated` | `adjacent`
- для `attic`/`unheated` задаётся `n`, либо `t_adj` (температура смежного объёма)
- `beta` — надбавка на ориентацию, по умолчанию 1,0
- `door_infiltration.H` — высота здания, м; включает надбавку 0,22·H
  (тип входа переопределяется полем `k`, по умолчанию 0,22)
- `vent.mode`: `ach` (кратность, ч⁻¹) | `flow` (м³/ч) | `per_area` (м³/ч на м²)
- `ground` — блок метода зон, необязательный
- `gains` — теплопоступления, Вт, вычитаются

Конструкция задаётся либо готовым `R`, либо `layers` = список [δ, λ];
`r` — коэффициент теплотехнической однородности; `R_si`/`R_se` переопределяют
сопротивления теплоотдачи.

## 3. Что проверять после расчёта

| Проверка | Норма |
|---|---|
| Замыкание периметра по осям | сходится точно |
| Сумма площадей зон = площадь пола | < 0,5 % |
| Площади помещений: геометрия против экспликации | < 3 % |
| Остекление: геометрия против ведомости фасадов | < 3 % |
| Замыкание баланса: Σ по помещениям = Σ по конструкциям | округление |
| Удельная нагрузка, Вт/м² | 40…70 для утеплённого дома, 90…130 при большом остеклении |
| Rфакт против Rтр | по каждой конструкции |

Удельный показатель — самый быстрый способ поймать грубую ошибку. Если утеплённый
коттедж вышел 200 Вт/м², ошибка есть; если 25 Вт/м² — тоже.

## 4. Повторный расчёт

При пересчёте всегда прикладывать таблицу дельт:

| Фактор | Δ, Вт |
|---|---|
| Уточнение остекления | +780 |
| Врывание через наружную дверь (не учитывалось) | +384 |
| Надбавка β = 1,10 (не учитывалась) | +430 |
| Переход tн −30 → −27 °C | −560 |

Это первое, что спросят и заказчик, и эксперт. Восстановить дельту задним числом
почти невозможно — фиксировать сразу.
