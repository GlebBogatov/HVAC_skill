# Чертежи

## 1. Наложение на подложку АР

Планы ОВ выпускаются наложением слоя на страницы архитектурного PDF. Причина
не в экономии времени: при перечерчивании геометрия неизбежно расходится с АР
на 20…50 мм, и петли садятся на «свои» стены, а не на реальные. При наложении
расхождение исключено по построению.

Процедура калибровки — `ishodnye-dannye.md`, п. 3. Ключевое требование:
сходимость по контрольным пролётам осей лучше 0,1 %. Проверять по всем осям,
а не по одной паре — неравномерное масштабирование листа встречается часто.

```bash
python3 scripts/sheet_pdf.py --ar AR.pdf --page 5 \
        --calib calib.json --layer ov_cokol.json --out ОВ-05.pdf
```

Скрипт печатает невязку по контрольным точкам и **отказывается собирать лист**,
если она хуже заданного порога (по умолчанию 0,2 %).

### Типовые ошибки при сборке

- **Двойной штамп.** У листа АР свой штамп в правом нижнем углу. При уменьшении
  подложки он переезжает вместе с ней. Закрывать белым прямоугольником и ставить
  свой поверх.
- **Белый текст.** Если перед отрисовкой текста не сбросить цвет заливки после
  белой плашки, текст рисуется белым по белому. Проверять растром, а не по
  структуре PDF.
- **Наезд легенды на план.** Резервировать колонку под ведомость и легенду
  до отрисовки подложки, а не после.

Готовый лист **обязательно растрировать и посмотреть глазами**:
`pdftoppm -r 120 -png ОВ-05.pdf out`. Проверка структуры PDF ошибок отрисовки
не ловит.

## 2. Формат слоя ОВ (layer.json)

Модельные координаты в мм, начало — на пересечении крайних осей.

```json
{
  "title": "Цоколь. План напольного отопления",
  "sheet": "ОВ-05",
  "polylines": [
    {"layer": "TP-K1", "pts": [[1200,800],[4600,800],[4600,3080]], "width": 0.5, "color": "red"},
    {"layer": "TP-SUPPLY", "pts": [[1200,800],[900,400]], "style": "dashed"}
  ],
  "circles": [{"layer": "RISER", "c": [900, 400], "r": 60}],
  "texts": [{"layer": "TEXT", "pt": [2900, 1900], "text": "К1  50,2 м", "h": 120}],
  "rects": [{"layer": "EQUIPMENT", "p1": [800,300], "p2": [1100,500]}],
  "table": {
    "title": "Ведомость петель",
    "header": ["Петля", "Помещение", "S, м²", "Шаг", "L, м"],
    "rows": [["К1", "Кладовая", "6,82", "200", "50,2"]]
  },
  "stamp": {
    "object": "{наименование объекта}",
    "sheet_name": "Цоколь. План напольного отопления",
    "code": "{шифр}-ОВ", "sheet_no": "5", "sheets": "14",
    "designer": "{исполнитель}", "date": "{дата}"
  }
}
```

Тот же файл подаётся в `scripts/dxf_export.py` — чертёж PDF и DXF получаются
из одного источника и не могут разойтись.

## 3. Слои DXF

| Слой | Содержание | Цвет ACI |
|---|---|---|
| `TP-<имя>` | петля тёплого пола | 1 (красный) |
| `TP-SUPPLY` | подводки от петли до коллектора | 6 (сиреневый) |
| `HEAT-MAINS-T1` | магистраль подачи | 1 |
| `HEAT-MAINS-T2` | магистраль обратки | 5 (синий) |
| `EQUIPMENT` | приборы, коллекторные шкафы, котёл | 3 (зелёный) |
| `RISER` | стояки через перекрытие | 2 (жёлтый) |
| `SLEEVE` | гильзы в перегородках | 4 (голубой) |
| `ROOMS` | контуры помещений | 8 (серый) |
| `AXES` | оси | 8, штрихпунктир |
| `TEXT` | выноски, марки, длины | 7 (белый/чёрный) |
| `DIM` | размеры | 7 |

Единицы — миллиметры. Начало координат фиксируется в записке.

`scripts/dxf_export.py` пишет DXF R12 без внешних зависимостей — открывается
в AutoCAD, nanoCAD, LibreCAD, BricsCAD.

## 4. Что должно быть на плане ТП

- контуры помещений с номерами и наименованиями по экспликации АР;
- поля петель с раскладкой, маркой петли и шагом;
- подводки от каждой петли до коллектора (пунктиром);
- коллекторные шкафы с марками;
- гильзы в местах пересечения перегородок;
- стояки через перекрытие;
- ведомость петель: марка, помещение, площадь, шаг, длина поля, длина подводок,
  итого;
- легенда и условные обозначения;
- примечания: тип трубы, отступ от наружных стен, толщина стяжки,
  требование опрессовки до заливки.

## 5. Что должно быть на плане отопления

- магистрали Т1/Т2 с диаметрами и уклонами;
- отопительные приборы с марками и мощностями;
- запорная и балансировочная арматура;
- стояки, гильзы, компенсаторы;
- узлы врезки с выносками на листы узлов;
- спецификационные позиции в кружках-выносках.

**Приборы и оборудование выносить на план отопления, а не на план ТП.** На плане
ТП — только петли, коллекторы, подводки; радиаторы, конвекторы, узлы — на плане
отопления (иначе оба слоя превращаются в кашу).

## 5а. Размещение оборудования и подписей

Правила читаемости, за которые цепляется заказчик и экспертиза:

- **Оборудование и приборы — по стенам, вне зоны открывания дверей.** Котёл,
  бойлер, коллекторы, радиаторы располагать вдоль стен; зону открывания двери
  показывать штриховкой (дугой) и держать свободной. Прибор, стоящий на пути
  двери, — типовое замечание.
- **Свободный проход в технических помещениях** показывать пунктиром, ≥ 1000 мм.
- **Таблицы, ведомости и легенды — в колонках вне поля чертежа**, не поверх
  плана. Чертёж — слева/по центру, таблицы — справа отдельной колонкой.
- **Шрифт подписей — не мельче ~10…13 pt** (в аксонометрии `isometry.py` минимум
  жёстко 12). Наложение одного текста на другой недопустимо.

## 6. Формат, рамка, основная надпись

Формат листа, рамку и основную надпись выполнять по **ГОСТ Р 21.101-2020**
и **ГОСТ 2.301-68** (полный разбор с формами и размерами — `dokumentaciya.md`):

- форматы А4…А0 по ГОСТ 2.301-68, планы ОВ обычно А1/А2;
- рамка сплошной основной линией, поле **20 мм слева**, по **5 мм** с трёх сторон;
- основная надпись листов рабочих чертежей — **форма 3** (185×55 мм), правый
  нижний угол; спецификации и текстовые листы — формы 5/6.

При наложении на подложку АР рамка и формат уже заданы архитектурным листом —
переиспользовать их, свой штамп ставить поверх закрытого штампа АР
(см. п. 1, «двойной штамп»). Для самостоятельного листа ОВ (не на подложке)
`sheet_pdf.py --frame` рисует рамку с полями 20/5.

## 7. Проверка перед выпуском

| Проверка | Как |
|---|---|
| Лист открывается и печатается | растрировать и посмотреть |
| Формат и рамка по ГОСТ (поле 20 мм слева, 5 мм с трёх сторон) | измерить на растре |
| Основная надпись — форма 3, 185×55, все графы заполнены | растр |
| Штамп один (не двойной с АР), читается | растр |
| Петли не выходят за стены | наложение на подложку |
| Марки петель на плане = марки в ведомости | сверить списком |
| Сумма длин в ведомости = сумма в спецификации | посчитать |
| Ведомость и легенда не перекрывают чертёж | растр |
| Масштаб в штампе соответствует фактическому | измерить пролёт оси |
| Номера листов сквозные, соответствуют общим данным | сверить |
