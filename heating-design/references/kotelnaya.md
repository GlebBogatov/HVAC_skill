# Котельная

## 1. Подбор котла

Мощность: Qк = Qо · 1,1 (запас) + Qгвс, если нет приоритета ГВС.
При штатном приоритете ГВС мощность на ГВС не суммируется — котёл на время
нагрева бойлера полностью переключается на него.

Загрузка в расчётном режиме 60…80 % — оптимум. Ниже 50 % котёл тактует на
межсезонье, выше 90 % не остаётся резерва на разогрев бойлера.

| Тип | Когда | Замечание |
|---|---|---|
| Настенный конденсационный | ТП как основная система, график 40/30 | КПД реализуется только при обратке ниже 55 °C |
| Настенный атмосферный | компактно, до 35 кВт | требует стабильного давления газа |
| Напольный чугунный | ресурс, нечувствительность к качеству теплоносителя | **обязательна защита от низкотемпературной коррозии** |
| Напольный стальной | средний вариант | |

**Одноконтурный + бойлер косвенного нагрева всегда предпочтительнее двухконтурного**,
если есть душ или больше одной точки водоразбора: двухконтурный даёт колебания
температуры и не держит одновременный разбор.

## 2. Защита чугунного теплообменника

Температура обратки котлового контура — не ниже 50 °C (для конденсационных
котлов, наоборот, чем ниже, тем лучше — не путать).

Решения:

- термостатический смесительный клапан (ESBE VTC 511, Danfoss ESBE-аналог) на
  байпасе котла — простое и надёжное;
- четырёхходовой смесительный клапан с сервоприводом — при погодозависимой автоматике;
- гидрострелка + отдельный котловой насос — при нескольких разнотемпературных контурах.

График 70/50 для чугунного котла с ТП — компромисс: при более низкой обратке
нужна защита, при более высокой падает КПД и растут потери через трубопроводы.

## 3. Бойлер косвенного нагрева

| Разбор | Объём |
|---|---|
| Мойка + раковина | 80…100 л |
| + один душ | 150…200 л |
| + ванна | 200…300 л |
| Две ванны / несколько душей одновременно | ≥ 300 л или каскад |

**Полезная теплота нагрева:** Q = V · ρ · c · Δt / 3600, кВт·ч
Для 160 л от 10 до 60 °C: 160 · 4,187 · 50 / 3600 = 9,3 кВт·ч.

**Время нагрева** при приоритете ГВС: τ = Q / Nкотла.
9,3 / 14,9 = 0,62 ч = 37 мин.

**Запас смешанной воды 40 °C** из бака 60 °C при ХВС 10 °C:
V₄₀ = V · (60 − 10)/(40 − 10) = V · 1,67.
160 л → 267 л, при расходе душа 9 л/мин это 29 минут непрерывного разбора.

Мощность змеевика должна быть не меньше мощности котла — иначе бойлер
становится узким местом. Обычно змеевик 25…40 кВт, ограничение всё равно по котлу.

**Котёл и бойлер одного бренда** — штатный датчик NTC подключается напрямую
к плате котла, приоритет ГВС работает без внешнего контроллера. Разные бренды
означают либо реле, либо отдельный контроллер, либо ручной режим.

Магниевый анод — обязательно, с занесением в раздел эксплуатации: проверка
раз в год, замена раз в 2…3 года. Жёсткая вода из скважины без водоподготовки
убивает змеевик за 3…5 лет.

## 4. Расширительный бак

Vб = Vсист · β / (1 − (Pнач + 1)/(Pпред + 1)), где давления избыточные, бар.

Коэффициент объёмного расширения воды β:

| t, °C | 40 | 50 | 60 | 70 | 80 | 90 |
|---|---|---|---|---|---|---|
| β | 0,0079 | 0,0121 | 0,0171 | 0,0227 | 0,0287 | 0,0359 |

Для растворов гликоля β умножается на 1,1 (30 %) или 1,2 (50 %).

**Объём системы** оценивать по составляющим, а не по «10 л на кВт»:

| Элемент | Объём |
|---|---|
| Труба ТП 16×2,0 | 0,113 л/м |
| Труба ТП 20×2,0 | 0,201 л/м |
| Котёл | 20…60 л (чугунный), 2…5 л (настенный) |
| Бойлер (первичный контур, змеевик) | 3…8 л |
| Радиатор алюминиевый, секция | 0,4 л |
| Конвектор напольный | 1…3 л |
| Труба стальная/нерж 28×1,2 | 0,53 л/м |

Пример: ТП 610 м × 0,113 = 69 л + котёл 25 + прочее 6 ≈ 100 л.

Pнач = статическая высота системы + 0,3 бар, обычно 1,0…1,5 бар.
Pпред = настройка предохранительного клапана минус 0,5 бар, обычно 2,5…3,0 бар.

Результат округлять вверх до стандартного ряда (8, 12, 18, 24, 35, 50 л)
с запасом на догрузку системы.

## 5. Обязательная обвязка

- группа безопасности котла: предохранительный клапан 3 бар, автовоздухоотводчик,
  манометр — **между котлом и первой запорной арматурой, без отсекающих кранов**;
- фильтр-грязевик перед котлом и перед каждым насосом;
- узел подпитки от ХВС: обратный клапан, редуктор, счётчик или хотя бы вентиль
  с пломбировкой;
- дренажные краны в нижних точках каждого контура;
- воздухоотводчики в верхних точках;
- отсечная арматура для демонтажа любого узла без слива системы.

## 6. Помещение котельной (СП 402.1325800.2018)

| Требование | Значение |
|---|---|
| Объём при мощности до 30 кВт | ≥ 7,5 м³ |
| Объём при 30…60 кВт | ≥ 13,5 м³ |
| Высота | ≥ 2,5 м |
| Остекление (легкосбрасываемые конструкции) | ≥ 0,03 м² на 1 м³ объёма |
| Открывающаяся створка окна | обязательна |
| Дверь наружу или в коридор | ширина ≥ 0,8 м |
| Приток | 3 ч⁻¹ + воздух на горение |
| Вытяжка | из верхней зоны |
| Газоанализатор + клапан-отсекатель | при мощности > 60 кВт, рекомендуется всегда |

Проверить, что окно котельной по АР проходит: 15,11 м³ × 0,03 = 0,45 м²
требуемых при фактических 0,55 м² — проходит.

Дымоход и приточный воздуховод должны быть заложены в АР. Если их там нет —
это открытый вопрос, требующий правки АР, а не проблема раздела ОВ.
