# Оборудование: источники и подбор

## 1. Три источника и их роли

Разделение обязательное: технические характеристики берутся у производителя,
наличие и цена — у дистрибьютора. Подбор «по карточке интернет-магазина»
регулярно даёт неверный Kv, неверное присоединение и снятый с производства артикул.

| Источник | Роль | Что брать |
|---|---|---|
| **VALTEC** — [valtec.ru](https://valtec.ru/) | производитель | техданные, паспорта, Kv, габариты, присоединения, чертежи DWG, **BIM-модели Revit**, прайс, программы расчёта |
| **Лунда** — [lunda.ru](https://lunda.ru/) | дистрибьютор | наличие, цена, широкая номенклатура сторонних брендов (насосы, котлы, автоматика, КИП, водоподготовка) |
| **Терем** — [teremonline.ru](https://www.teremonline.ru/), [teremopt.ru](https://www.teremopt.ru/) | дистрибьютор / розница | наличие, цена, аналоги и замены, теплотехника европейских брендов |

**Порядок работы.** Сначала подобрать по техническим характеристикам у
производителя. Затем проверить наличие у дистрибьютора. Если позиции нет —
искать аналог, но снова через характеристики, а не через похожую картинку.
В спецификацию писать артикул производителя, а не артикул магазина: артикулы
магазинов меняются и в другом регионе не ищутся.

## 2. Карточка позиции

Каждая позиция спецификации собирается в машиночитаемую карточку — шаблон
`assets/equipment_item.json`. Смысл в том, что при переходе на BIM эти же поля
лягут в параметры семейства Revit без переписывания: собранная сейчас карточка
переживёт смену инструмента.

| Поле | Зачем | Обязательно |
|---|---|---|
| `name` | наименование для спецификации | да |
| `article` | артикул производителя | да |
| `manufacturer` | производитель | да |
| `series` | серия по каталогу (для поиска BIM-модели) | если есть |
| `unit`, `qty` | единица и количество | да |
| `connection` | присоединение (G¾″ НР, Ø16 евроконус, пресс 28) | да |
| `dn`, `pn`, `t_max` | диаметр, давление, температура | да |
| `kv` | пропускная способность арматуры | для регулирующей |
| `power_kw` | мощность | для приборов и котлов |
| `dimensions` | габариты Д×Ш×В, мм | да |
| `weight_kg` | масса | для BIM и нагрузок |
| `source_tech` | URL страницы производителя | да |
| `source_stock` | URL позиции у дистрибьютора | да |
| `checked` | дата проверки наличия | да |
| `bim` | блок BIM-атрибутов, см. `bim.md` | по возможности |

Дата проверки — не формальность. Номенклатура живёт около года: позиция,
подобранная полгода назад, может быть снята. Перед выпуском спецификации
карточки со старой датой перепроверяются.

## 3. Трубы тёплого пола

| Материал | Применение | Замечание |
|---|---|---|
| **PE-Xa (пероксидная сшивка)** | основной выбор для ТП | эффект памяти формы — залом восстанавливается прогревом; лучшая стойкость к точечным нагрузкам |
| PE-Xb (силановая сшивка) | бюджет | ниже степень сшивки, хуже гибкость, залом не восстанавливается |
| PE-RT | ТП, низкие температуры | дешевле, ниже рабочая температура |
| Металлопластик PE-X/AL/PE-X | ТП, магистрали | держит форму, фитинги требуют обслуживания |

**Кислородный барьер EVOH обязателен** для любой трубы ТП: без него кислород
диффундирует в теплоноситель и убивает стальные и чугунные элементы за несколько
сезонов.

Внимание к маркировке: линейка с названием «PEX-EVOH» у ряда производителей —
это PE-X**b**, а PE-X**a** идёт отдельной позицией каталога. Проверять по
паспорту, а не по названию в карточке магазина.

Типоразмер 16×2,0 — стандарт для жилья и малых объектов; 20×2,0 — при больших
полях и длинных петлях.

## 4. Трубопроводы котельной

| Система | Где | Замечание |
|---|---|---|
| Нержавеющая сталь, пресс (AISI 304) | обвязка котельной | PN16, до 95 °C; пресс-фитинги V-профиль |
| Медь, пайка или пресс | обвязка котельной | дороже, требует квалификации |
| Сталь чёрная, сварка | котельные большой мощности | коррозия, требует окраски |
| Полипропилен | бюджетные системы | не применять на котловом контуре чугунного котла |

Типоразмеры обвязки уточнять по расходу и допустимой скорости 0,5…1,0 м/с
в магистралях. Ориентир для коттеджной котельной: котёл — гидрострелка —
коллектор 28×1,2, подключения бойлера и насосных групп 22×1,2.

## 5. Что подбирать у дистрибьютора

VALTEC не производит котлы, бойлеры, насосы и автоматику — эти позиции ищутся
в каталогах Лунды и Терема по техническим требованиям из `kotelnaya.md`:

- **котёл** — по мощности с запасом 10 %, тип по разделу «Подбор котла»;
- **бойлер косвенного нагрева** — по объёму и мощности змеевика;
- **насосы** — по расходу и напору контура;
- **автоматика и КИП** — по схеме управления;
- **водоподготовка** — по анализу воды.

Правило совместимости: котёл и бойлер одного бренда подключаются штатным
датчиком NTC напрямую к плате, приоритет ГВС работает без внешнего контроллера.
Разные бренды означают реле или отдельный контроллер — и это отдельная позиция
в спецификации, о которой забывают.

## 6. Отопительные приборы догрева

| Тип | Когда | Ограничение |
|---|---|---|
| Напольный приставной конвектор | вдоль витражей, при готовой стяжке | занимает место у пола |
| Внутрипольный конвектор | панорамное остекление | требует ≥ 100 мм чистой глубины — в тонкой стяжке по ЭППС 20 мм **не встанет** |
| Радиатор панельный / секционный | стандартный догрев | под окном, длина ≥ 60 % ширины проёма |
| Полотенцесушитель водяной | санузлы | закрывает дефицит 100…300 Вт |

Мощность прибора в каталоге указывается для графика 75/65/20. При графике
70/50/18 пересчитывать по Δtлог: коэффициент примерно 0,72…0,78. Взятая
напрямую паспортная цифра даёт прибор слабее на четверть.

## 7. Спецификация

Позиция — наименование — марка/артикул — единица — количество — примечание.
Отдельные спецификации: оборудование, материалы напольного отопления,
расходные материалы. Общая куча в одной таблице неудобна при закупке.

Количество трубы — с запасом 5…7 % на подрезку и брак, **отдельной строкой**,
а не внутри расчётной длины: иначе при следующем пересчёте запас потеряется
или удвоится.
