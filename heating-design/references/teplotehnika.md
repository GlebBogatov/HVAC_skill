# Теплотехнический расчёт ограждающих конструкций

## 1. Сопротивление теплопередаче

R₀ = Rsi + Σ(δᵢ/λᵢ) + Rse

| Величина | Значение | Условие |
|---|---|---|
| Rsi = 1/αв | 0,115 | αв = 8,7 Вт/(м²·К), стены и полы |
| Rsi | 0,096 | αв = 10,4, для потолков с тёплым полом сверху не применять |
| Rse = 1/αн | 0,043 | αн = 23, наружный воздух |
| Rse | 0,115 | αн = 8,7, вентилируемый фасад, чердак, подполье |

**Вентилируемый фасад.** Слои снаружи от вентзазора (облицовочный кирпич,
керамогранит, сайдинг) в расчёт R₀ **не входят** — воздух в зазоре имеет
температуру наружного. Вместо Rse принимается 0,115.

**Коэффициент теплотехнической однородности r.** Для каркасных конструкций
с деревянными балками r = 0,85…0,92; для кладки с гибкими связями r = 0,92…0,97.
R₀ᵖ = r · R₀ по глади. Если r не считался — записать допущение.

## 3. Светопрозрачные конструкции

Приведённое сопротивление указывается производителем. Ориентиры:

| Заполнение | R₀, м²·К/Вт | U, Вт/(м²·К) |
|---|---|---|
| Однокамерный стеклопакет | 0,35…0,40 | 2,9…2,5 |
| Однокамерный с i-стеклом | 0,50…0,55 | 2,0…1,8 |
| Двухкамерный обычный | 0,50…0,55 | 2,0…1,8 |
| Двухкамерный энергосберегающий (i-стекло + аргон) | 0,65…0,75 | 1,5…1,3 |
| Дверь наружная стальная утеплённая | 0,55…0,65 | 1,8…1,5 |
| Дверь наружная деревянная | 0,40…0,50 | 2,5…2,0 |

**Формула стеклопакета — самое частое белое пятно в АР.** Разница между 0,55 и
0,70 на 30 м² витражей при Δt = 45 К даёт около 800 Вт, то есть почти целый
конвектор. Если формула неизвестна — принять худший реалистичный вариант,
записать в открытые вопросы и посчитать чувствительность.

## 4. Проверка по СП 50.13330.2012

ГСОП = (tв − tот) · zот, где tот и zот — средняя температура и продолжительность
периода со средней суточной ≤ 8 °C (СП 131.13330.2020).

Rтр = a · ГСОП + b (таблица 3 СП 50.13330.2012):

| Конструкция | Группа 1: жилые, лечебные, детские, школы | Группа 2: общественные, административные, бытовые | Группа 3: производственные |
|---|---|---|---|
| Стены | 0,00035 / 1,4 | 0,0003 / 1,2 | 0,0002 / 1,0 |
| Покрытия, чердачные перекрытия | 0,00045 / 1,9 | 0,0004 / 1,6 | 0,00025 / 1,5 |
| Перекрытия над подвалами и подпольями | 0,00045 / 1,9 | 0,00035 / 1,3 | 0,0002 / 1,0 |
| Окна, витражи, балконные двери | 0,000075 / 0,15 | 0,00005 / 0,3 | 0,000025 / 0,2 |

Пары чисел — это a / b. Группу выбирать по назначению здания; спортзал, магазин,
офис — группа 2. Перед выпуском сверить с действующей редакцией таблицы 3.

Пример: ГСОП = 4 449 °C·сут, группа 2 → стены 2,53; чердак 3,38; окна 0,52.

Несоответствие Rфакт < Rтр не останавливает расчёт: теплопотери считаются по
фактическому R, а факт несоответствия выносится в открытые вопросы с оценкой,
сколько ватт и денег стоит доутепление.

## 5. Метод зон: полы по грунту и заглублённые стены

Через U такие конструкции не считаются — грунт даёт растянутое во времени и
пространстве сопротивление. Применяется зонная методика.

**Правило.** Разбивка ведётся по развёртке от уровня земли: сначала вниз по
наружной стене, затем от стены внутрь по полу. Зона — полоса шириной 2 м.

| Зона | Развёртка от уровня земли, м | R зоны (неутеплённой), м²·К/Вт |
|---|---|---|
| I | 0…2 | 2,1 |
| II | 2…4 | 4,3 |
| III | 4…6 | 8,6 |
| IV | остальное | 14,2 |

Утепление добавляется к R зоны: Rзоны+утепл = Rзоны + Σ(δут/λут).
ЭППС 50 мм даёт +1,563; ЭППС 80 мм даёт +2,5.

**Пример.** Пол цоколя на отм. −2,575, земля −1,420 → заглубление стены h = 1,155 м.
Вся стена в зоне I. На пол зона I переходит остатком 2,0 − 1,155 = 0,845 м полосой
по периметру, дальше 2 м зона II, дальше 2 м зона III, остаток — зона IV.

Q = Σ Aзоны · (tв − tн) / Rзоны. Надбавка β на ориентацию к грунтовым
конструкциям **не применяется** — солнце и ветер до них не доходят.

**Контроль:** сумма площадей зон должна равняться геометрической площади пола.
Расхождение больше 0,5 % — ошибка в разбивке. `scripts/heatloss.py` проверяет это сам.

**Углы.** В классической методике участки пола в углах наружных стен входят в
зону I дважды. Скрипт реализует это через прямоугольную аппроксимацию по периметру
и площади; для сложной формы результат консервативен (в запас).

## 6. Смежные неотапливаемые объёмы

Q = A · U · (tв − tн) · n, где n — коэффициент, учитывающий, что за конструкцией
не наружный воздух:

| Объём | n |
|---|---|
| Холодный чердак | 0,9 |
| Неотапливаемый подвал со световыми проёмами | 0,6 |
| Неотапливаемое подполье без проёмов, ниже уровня земли | 0,4 |
| Неотапливаемый гараж, тамбур, пристройка | 0,6 |
| Наружный воздух | 1,0 |

Строго n определяется из теплового баланса неотапливаемого помещения. При малых
площадях (до 20 м²) разница с табличным значением укладывается в ±50 Вт —
допустимо, но допущение записать.

Альтернатива точнее: задать расчётную температуру смежного объёма (например,
гараж +5 °C) и считать по фактическому Δt. Скрипт поддерживает оба способа.
