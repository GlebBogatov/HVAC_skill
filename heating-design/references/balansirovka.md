# Балансировка системы отопления

Балансировка — обязательный раздел проекта и отдельный лист (в марке ОВ). Без
настройки расходомеров и клапанов система работает по самому лёгкому контуру:
ближние приборы перегреваются, дальние недополучают. Лист даёт монтажнику
конкретные настройки, а не «отрегулировать по месту».

## 1. Тёплый пол — расходомеры коллектора

Считает `scripts/hydro.py` (блок «Балансировка» в выводе). По каждой петле:

- **расчётный расход, л/мин** — на него выставляется расходомер;
- **Δp петли** и **избыток напора к гашению** = Δp индексной петли − Δp данной петли.

Правило: **индексную (самую тяжёлую) петлю оставить открытой**, остальные
придушить расходомером на их избыток напора, выставив расчётный расход. Тогда
все петли получают проектный расход при одном напоре насоса.

Расходомер настраивают по шкале л/мин (Valtec VTc.596, Rehau HKV-D и аналоги).
Разброс длин петель на коллекторе ≤ 30…40 % — иначе избыток на короткой петле
слишком велик и расходомер работает на пределе (см. `teplyj-pol.md`).

## 2. Радиаторы (двухтрубная) — преднастройка клапанов

У каждого прибора — термостатический клапан на подаче (с преднастройкой) и
запорно-регулировочный на обратке. Настройку берут по **требуемому Kv**:

    Kv = G / √Δpрасп,  где G — расход прибора, м³/ч; Δpрасп — располагаемый
    перепад на приборе, бар (1 бар = 100 кПа).

**Располагаемый перепад растёт с удалённостью «наоборот»:** ближние к насосной
группе приборы имеют больший располагаемый перепад (меньше потерь в подводящих
магистралях) и требуют большего дросселирования; дальние — меньший. Пример из
практики: у надстройки Δpрасп ≈ 20 кПа, у цоколя ≈ 11 кПа — ближние клапаны
закрывают сильнее. По Kv выбирают позицию преднастройки по таблице клапана.

Расход прибора: G = 0,86 · Qприбора / Δt (кг/ч; для радиаторов Δt = 20 К обычно).

## 3. Что на листе «Балансировка»

1. **Расходомеры ТП** по всем петлям: расход л/мин, Δp петли, гасимый избыток,
   пометка индексной петли на каждом коллекторе.
2. **Преднастройка термоклапанов приборов**: расход, располагаемый перепад,
   требуемый Kv, позиция клапана.
3. **Порядок пусконаладки** по шагам: заполнение и опрессовка → выставить расходы
   ТП по расходомерам → преднастройка клапанов приборов → прогрев и проверка
   температур по помещениям → корректировка → пломбировка настроек.
4. **Таблица контрольных сумм** с графой «факт» — под подпись при пусконаладке
   (акт балансировки).

## 4. Порядок работы в скилле

1. Посчитать гидравлику: `hydro.py` даёт по каждой петле расход л/мин и избыток
   напора к гашению — это готовые настройки расходомеров ТП.
2. Для радиаторов — посчитать Kv по расходу и располагаемому перепаду (по
   удалённости от насосной группы), выбрать позицию по таблице клапана.
3. Свести на лист «Балансировка системы отопления» (в составе марки ОВ,
   см. `dokumentaciya.md`) с порядком пусконаладки и таблицей контрольных сумм.
