## 2. Разбор PDF архитектурного проекта

Растрировать нужные листы и читать глазами — размерные цепочки, отметки, составы.

```bash
python3 -c "
import pdfplumber
with pdfplumber.open('AR.pdf') as pdf:
    p = pdf.pages[4]
    print(p.width, p.height)
    for w in p.extract_words():
        print(round(w['x0']), round(w['top']), w['text'])
"
```

`extract_words` с координатами даёт и текст марок осей, и их положение в точках —
это сразу материал для калибровки (раздел 3).

Для растра — `pdftoppm -r 150 -png -f 5 -l 5 AR.pdf lst5`.

**Что снимать с каждого типа листа:**

- **План этажа** — площади по экспликации, размерные цепочки, длины наружных
  стен по помещениям, положение перегородок, проёмы, отметки пола, оси.
- **Разрез** — отметки земли, пола, перекрытий, конька; высоты этажей;
  толщины перекрытий. Отсюда считается заглубление цоколя и высота здания H
  для надбавки на врывание.
- **Узлы** — составы стен, кровли, полов послойно с толщинами и марками
  материалов. Марка утеплителя даёт λ по каталогу производителя.
- **Фасады** — высоты проёмов (на планах их нет), отметки низа и верха витражей.
- **Ведомость отделки фасадов** — площади облицовки; используется для
  независимого контроля площади остекления.
- **Обмерочный чертёж** (реконструкция) — фактические размеры существующих
  проёмов, которые расходятся с проектными.

## 3. Калибровка листа PDF для наложения

Цель — получить два коэффициента: масштаб (pt на мм модели) и смещение начала
координат, отдельно по X и Y.

1. Найти на листе две марки осей, разнесённые максимально далеко (например, ось 1
   и ось 4), и снять их координаты в точках PDF.
2. Из размерной цепочки взять модельное расстояние между ними в мм.
3. scale = (pt₂ − pt₁) / (мм₂ − мм₁).
4. **Проверить по всем остальным пролётам**: 1–2, 2–3, 3–4, А–Б. Сходимость
   должна быть лучше 0,1 %. Если хуже — лист отмасштабирован неравномерно
   (вставлен растр, разные фрагменты в разном масштабе), накладывать нельзя,
   нужно перечерчивать.
5. Масштабы по X и Y считать раздельно и сравнить: расхождение больше 0,5 %
   означает неравномерное растяжение.

Формат `calib.json` для `scripts/sheet_pdf.py`:

```json
{
  "page": 5,
  "x": {"pt1": 141.7, "mm1": 0, "pt2": 660.2, "mm2": 9880},
  "y": {"pt1": 520.4, "mm1": 0, "pt2": 210.9, "mm2": 5900},
  "checks": [
    {"axis": "x", "mm": 3590, "pt_expected": 330.2},
    {"axis": "y", "mm": 2950, "pt_expected": 365.6}
  ]
}
```

Скрипт печатает невязку по каждой контрольной точке. Читать её обязательно:
0,05 % — норма, 2 % — накладывать нельзя.

Ось Y в PDF растёт снизу вверх, в строительных координатах обычно тоже, но
разные генераторы PDF ведут себя по-разному — знак масштаба определять по
двум точкам, а не предполагать.

## 4. Чтение DXF

Если АР пришёл в DXF — это лучший случай: геометрия снимается точно.

- Единицы почти всегда мм; проверить по известному размеру (толщина стены,
  пролёт осей).
- Начало координат привязать к пересечению крайних осей и зафиксировать
  в записке — все последующие чертежи ОВ считать в этой системе.
- Площади помещений брать по замкнутому контуру внутренних граней стен.
- Сверить с экспликацией АР: расхождение до 3 % нормально (архитектор
  исключает проёмы лестниц, ниши), больше — разбираться.

## 5. Таблица источников

В записке обязательно вести таблицу «данные → лист». Она отвечает на главный
вопрос эксперта: откуда число. Формат:

| Данные | Источник |
|---|---|
| Площади помещений цоколя | АР, лист 5 |
| Отметки земли и перекрытий | АР, лист 8, разрез 1-1 |
| Состав НС-1 | АР, лист 13, узел Б |
| Климат, tн = −27 °C | СП 131.13330.2020, г. Самара |
| λ материалов | СП 50.13330.2012, прил. Т |
| R витражей 0,70 | принято, формула в АР не указана — открытый вопрос |

Последняя строка — важнее остальных: она честно отделяет данные от допущений.
