# Аксонометрическая (изометрическая) схема системы отопления

Схема системы отопления — обязательный лист рабочего комплекта для систем со
стояками и разветвлёнными магистралями. Она показывает то, чего не видно на
поэтажных планах: как система связана по вертикали, где стояки, отметки осей
труб, уклоны, точки выпуска воздуха и слива.

## 1. Норматив

- **ГОСТ 21.602-2016** (СПДС, РД систем ОВ) — систему отопления изображают
  схемой; для систем со стояками — **аксонометрической схемой**. Трубопроводы
  показывают одной сплошной основной линией, при пересечении без соединения —
  с разрывом. На схеме указывают: диаметры участков, отметки осей труб и приборов,
  уклоны, номера стояков (Ст1, Ст2…), отопительные приборы с типом и мощностью,
  запорно-регулирующую арматуру, воздуховыпуск и спускники.
- **ГОСТ 2.317-2011** (ЕСКД, аксонометрические проекции) — вид проекции. Для
  санитарно-технических и отопительных схем применяют **косоугольную фронтальную
  изометрическую проекцию**: оси X (горизонталь) и Z (вертикаль) лежат в плоскости
  чертежа, ось Y (глубина) — под углом **45°**, коэффициенты искажения по всем
  трём осям = 1,0.
- **ГОСТ 21.205-2016** — условные графические обозначения элементов
  санитарно-технических систем (приборы, арматура, оборудование).
- Линии — по **ГОСТ 2.303-68**; формат, рамка, основная надпись — по
  **ГОСТ Р 21.101-2020** (см. `dokumentaciya.md`).

## 2. Как строят проектировщики

**Ориентация осей.** Привязка к плану: направление вдоль фронта здания (по осям
цифр) — горизонтальная ось X; в глубину здания (по осям букв) — ось Y под 45°
вверх-вправо; вертикаль (этажи, стояки) — ось Z. Магистраль, идущая «в глубину»
плана, на схеме идёт под 45°; идущая вдоль фронта — горизонтально; стояки —
строго вертикально.

**Масштаб.** Обычно 1:100. Допускается схема без масштаба (пропорции сохраняют),
но отметки, диаметры и номера стояков обязательны в любом случае.

**Что показывают на схеме отопления:**

- ввод из котельной / тепловой узел, магистрали подачи Т1 и обратки Т2;
- стояки с номерами (Ст1, Ст2…), поэтажные горизонтальные подводки;
- отопительные приборы (радиаторы, конвекторы) с типом и мощностью;
- запорную и балансировочную арматуру, краны на приборах;
- воздухоотводчики в верхних точках, спускники в нижних;
- компенсаторы и неподвижные опоры на длинных магистралях;
- отметки осей труб и уклоны (обычно 0,002…0,003 в сторону спуска).

**Коллекторная (лучевая) система ТП.** Изометрию ведут от котельной →
распределительный коллектор → коллекторные шкафы этажей → лучи петель. Петли
тёплого пола на изометрии показывают условно (одной ниткой с маркой и длиной,
без раскладки — раскладка на плане). Каждый этаж — свой насосно-смесительный
узел (см. `kotelnaya.md`), это видно на схеме как отдельная группа на коллекторе.

**Цвета/линии.** Подача Т1 и обратка Т2 различают: на монохромном чертеже —
маркировкой у линий (Т1/Т2) и стрелками направления; в цвете — красный/синий.

## 3. Проекция (для scripts/isometry.py)

Фронтальная косоугольная изометрия, ось Y под углом α = 45°:

    Xэкр = x + k · y · cos(α)
    Yэкр = z + k · y · sin(α)          (Yэкр направлена вверх)

где x — вдоль фронта, y — в глубину, z — вертикаль; k — коэффициент по глубине.
По ГОСТ 2.317 для изометрии k = 1,0. На практике для читаемости плотных схем
глубину иногда сжимают (k = 0,5 — это уже фронтальная диметрия); строгая
изометрия — k = 1,0. Скрипт принимает k параметром (по умолчанию 1,0).

## 4. Формат входа scripts/isometry.py

Схема задаётся 3D-узлами (координаты в мм: x вдоль фронта, y в глубину, z вверх),
трубами между узлами и элементами в узлах.

```json
{
  "title": "Схема системы отопления",
  "sheet": "ОВ-09",
  "k_depth": 1.0,
  "nodes": {
    "kotel":  [0, 0, 0],
    "st1_0":  [3000, 2000, 0],
    "st1_1":  [3000, 2000, 3000],
    "rad1":   [4200, 2000, 3900]
  },
  "pipes": [
    {"from": "kotel", "to": "st1_0", "sys": "T1", "dn": 25},
    {"from": "st1_0", "to": "st1_1", "sys": "T1", "dn": 20, "riser": "Ст1"},
    {"from": "st1_1", "to": "rad1",  "sys": "T1", "dn": 15}
  ],
  "elements": [
    {"at": "kotel", "type": "boiler", "label": "Котёл"},
    {"at": "rad1",  "type": "radiator", "label": "Р-1  1,2 кВт"},
    {"at": "st1_1", "type": "valve", "label": ""}
  ],
  "labels": [
    {"at": "st1_1", "text": "+3.000", "dx": 120, "dy": 0}
  ]
}
```

Типы элементов: `boiler`, `radiator`, `convector`, `valve`, `pump`, `collector`,
`riser` (маркер стояка), `airvent` (воздухоотводчик), `drain` (спускник),
`expansion` (расширительный бак).

Скрипт проецирует 3D → 2D, пишет:

- **SVG** для быстрого просмотра (`--svg out.svg`);
- **layer.json** (`--layer out.json`) в формате, который читают `dxf_export.py`
  и `sheet_pdf.py` — чтобы схема прошла тот же выпуск, что и планы (DXF + лист
  на подложке или самостоятельный лист с рамкой `--frame`).

```bash
python3 scripts/isometry.py shema.json --svg ОВ-09.svg --layer ОВ-09.json
python3 scripts/dxf_export.py --layer ОВ-09.json --out ОВ-09.dxf
```

## 5. Проверка изометрии перед выпуском

| Проверка | Как |
|---|---|
| Стояки вертикальны, глубинные магистрали под 45° | визуально на растре/SVG |
| Все стояки пронумерованы (Ст1…) | сверить с планом |
| Диаметры проставлены на каждом участке | сверить с гидравликой |
| Отметки осей труб и приборов есть | сверить с разрезом АР |
| Воздухоотводчики в верхних точках, спускники в нижних | по схеме |
| Приборы с типом и мощностью, совпадают с планом и ведомостью | сверить |
| Т1/Т2 различимы (маркировка или цвет), стрелки направления | растр |
| Рамка и основная надпись по ГОСТ (форма 3) | см. `dokumentaciya.md` |
